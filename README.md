## Description

Evolving as it did on POSIX-inspired operating systems, even today
Python supports DevOps platforms far better than any other. From
government, military, and networking professionals – and from Dev, Ops,
to Sec - it’s no surprise that Python has become the go-to programming
language.

The first step in our training role-based opportunities, the mission of
**Python** **1100: Python for DevOps** is to provide a no-nonsense
interdiction into the concepts, modules, and topics that most software
operations personnel will need to know. By covering Python's core
operating system modules, collections, objects, as well as built-in
functions students will understand Python’s support for common operating
system operation. Along the way must-know concepts such as lambdas,
sorting, enumerations, slicing, f-strings, comprehensions, reporting,
and testing are covered.
